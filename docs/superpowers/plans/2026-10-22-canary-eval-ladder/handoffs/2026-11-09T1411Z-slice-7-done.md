- **Worker mounts shrink with `WESKIT_CONTAINER_MOUNTS`** (plan). *Why:* the executor is local, so plain-engine
  workflows run inside `submission_worker` and see its mounts. *Cost if wrong:* none: both shrink.
- **drs-filer keeps the full mount** (plan). *Why:* it serves metadata only. *Cost if wrong:* DRS still lists
  registry and secret objects; their files are reachable only through a workflow, which L2 closes.
- **The smoke input changes at L2** to the first object of a mounted tier (plan). *Cost if wrong:* the smoke run
  no longer covers `PROVENANCE.md` at L2.
- **`tier-reach` closed on a 400 `file does not exist` at submission** (beyond the plan's probe; spec
  clarification 12). *Why:* that refusal is the L2 control acting before the run starts. *Cost if wrong:* a 400
  for another cause still reports `error`; only this message counts as closed.

  template without Jinja, and the L2 macros are not YAML. *Cost if wrong:* a service defined inside a macro
  would be missed; none is.
- **The plan's open slices use plain `ssh`** (7, 8, 10; `18f8e90`). *Why:* `-F` skips the guest's host alias.
- **Task 2 implemented inline, not by a subagent.** *Why:* the plan gives the code verbatim and it is ~60
  lines; the review round covers it. *Cost if wrong:* none found by the tests.
- **The plan's "stop and ask" on a failed genomes run** (`slice-7-l2.md`, Task 3 Step 5) did not come up: the
  genomes run completed. Ruling for later levels: it is not a gate; a failed utility run is debugged and fixed
