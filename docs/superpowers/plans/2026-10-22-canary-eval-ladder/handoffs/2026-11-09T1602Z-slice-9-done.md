## What it built

- `spe_agent/airlock.py` (`fdcca13`): `redact(text, prefix)` replaces five classes (`sensitive_path`, `study_id`,
  `aws_secret_key`, `aws_access_key`, `secret_assignment`) by `[redacted:<class>]` and returns the class names,
  never the values; `settings(environ)` reads `SPE_AIRLOCK`/`SPE_STUDY_ID_PREFIX`; `python -m spe_agent.airlock`
  is the CLI the `airlock` probe runs. Decision 12's tests: `test_redact_and_cli_open_no_file` (no file opened by
  `redact` or the CLI) and `test_module_source_never_names_the_record` (no file I/O or record name in the source).
- The answer filter in the stream (`91241d8`): `create_app(..., airlock_prefix=...)`; on, each text message is
  held and sent redacted as one delta before its `TEXT_MESSAGE_END` (or before `RUN_FINISHED`/`RUN_ERROR`); the
  run log holds the redacted answer. `spe_harden_airlock` adds `SPE_AIRLOCK=1` and `SPE_STUDY_ID_PREFIX` to
  `agent.env` only when on; `create.yml` refuses it while `openwebui` is in `spe_frontends`.

## Rulings

- **The env lines only when on** (decision 3): off, `agent.env` renders byte for byte as before
  (`platform/dev/tests/test_agui_env.py`), so an instance without the switch keeps its agent container. Cost if
  wrong: none known; an always-present `SPE_AIRLOCK=0` would only have recreated every agent container once.
- **Whole messages are buffered**, since a pattern can span chunks (`STU` | `DY-0042`). Cost: with the airlock on,
  the user sees each message at once when the model finishes it, not token by token; tool-call events still
  stream.
- **The check is filtered to the `airlock` probe**: no instance can be at L5 before L4 exists, so
  `hardening.json`'s `level` stays 3 and the full suite would report the closed airlock as a mismatch by design.
  Cost if wrong: a probe passing in isolation while a full L5 run disagrees; the L4 plan's unfiltered L5
  controls run settles it.
- **`spe_harden_airlock` was already in `group_vars/all.yml`** (slice 3, for `hardening.json`): not added again.
- **Both `create_app` call sites in `__main__.py`** take the airlock setting and exit 2 on its configuration error.
- **The agent README's paragraph sits under *Runs***: the README has no *Service* section, and *Runs* already
  describes the stream's per-run behaviour.
- **Compaction summaries named in the gap line**: the task review found the compaction markers and `/compact`
  also bypass the filter; they went into the same `BACKLOG.md` line as tool results and reasoning.
