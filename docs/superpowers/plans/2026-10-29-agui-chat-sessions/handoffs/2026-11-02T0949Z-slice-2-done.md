**Rulings of the plan** (*decision, why, cost if wrong*):

1. The e2e script is Python Playwright (`platform/dev/e2e/sessions.py`). *Why:* the dev VM has it with its
   Chromium, and no Node Playwright. *Cost:* one file to port.
2. Opening a session remounts CopilotChat on a non-explicit thread. *Why:* an explicit `threadId` makes
   CopilotChat 1.79 clear the messages set before the mount. *Cost:* if a later CopilotKit clears on the first
   mount, opening shows an empty chat; the e2e reload check catches it.
3. The image sets `NEXT_MANUAL_SIG_HANDLE=true`, and `installShutdown()` warns when it is unset (clarification 2).
   *Why:* Next.js's own handler exits before a detached run is saved. *Cost:* a hand-run `server.js` without it
   loses a run in progress on stop; the warning says so.
4. An absent run log is recognised by `docker compose cp`'s own `Could not find the file` error
   (clarification 3). *Why:* the agent is stopped by then, and a check before stopping races its last write.
   *Cost:* a changed error text in a later Compose fails the export loudly.
5. `archive.yml` for the early output ran from the worktree with the main checkout's instance file and output.
   *Why:* the new `run_archive` code exists only in the worktree. *Cost:* none.
6. Hidden rows are left out until slice 3's *Show hidden*; they stay openable by URL. *Cost:* none.
