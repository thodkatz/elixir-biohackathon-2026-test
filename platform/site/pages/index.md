# Threat catalog

This is a catalog of threat models for AI agents operating in Secure Processing Environments. The [interactive table](interactive-table.md) lists every threat and can be searched, filtered and sorted; each threat has its own page. The **Metadata** section explains the fields of an entry and the values they can take.

![Overview of the SPE Range setup](assets/images/overview.svg){ .figure }

Entries are Markdown files in the [GitHub repository](https://github.com/kraatz/elixir-biohackathon-2026-test/tree/main/threats). To change or add one, edit it there; merged changes appear here within minutes.
